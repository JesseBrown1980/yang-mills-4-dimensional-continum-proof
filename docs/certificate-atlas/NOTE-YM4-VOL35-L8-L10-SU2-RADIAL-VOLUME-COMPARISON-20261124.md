## 1. Exact native gauge law, sampling and fixed geometry

Use the original 4D untwisted periodic Wilson measure
\[
 d\mu_{\beta,L}(U)\ \propto\
   \exp\{\beta\sum_{p\in\mathcal P}\operatorname{Re}U_p\}
   \prod_{\text{positive original links }e}dH_{SU(2)}(U_e).
\]
The numerical engine is VOL34's independently developed C++17 **symmetric Haar/local-multiplication Metropolis** algorithm: each proposed continuous-SU2 link change recomputes all six incident Wilson plaquettes directly and uses the exact Metropolis Wilson-action acceptance ratio. Its independent full-action-difference and site-wise gauge-invariance controls passed in VOL34. This work reruns the same source binary from **fixed new seeds**, rather than treating the previous L8 three-chain screen as a final result.

All measurements use the original spatial 0–1 plaquette trace \(P_x=\operatorname{Re}U_{p_x}\) and time direction 2. Define \(K_\beta(h)=E[P_0P_h]-(E P_0)^2\). The bounded normalized source \(F=(1+P)/2\) has all connected covariances divided by four; the ratios \(K(h)/K(0)\) are unaffected.

- **L8 \(\beta=2\): eight independent chains**, seeds 18101,18119,18133,18149,18169,18181,18199,18211. Each: **1,000 warmup sweeps**, 350 retained configurations, four full sweeps between observations; 2,800 saved configurations. Proposal acceptance ~0.4865–0.4868.

- **Separate L8 and L10 \(\beta=0\) Haar controls:** six independent seeds at each L, 25 initial independent-Haar refreshes then 500 independent saved configurations per chain: 3,000 controls per L.
- **Total:** **26 complete independent chains, 10,120 retained configurations**. The incomplete exported snapshot was excluded.

For each original periodic torus, the integer pair-displacement histogram is
\[
 H_{A,B}(h)=\#\{(x,y)\in A\times B:y-x=h\bmod L\},

## 2. Two independent spherical contractions agree on every saved field

For each retained continuous-SU2 Wilson field configuration, the new measurement engine evaluates the direct translational two-sphere average and an independently built exact integer displacement-histogram-weighted two-point convolution:
\[
 \operatorname{Cov}(M_A,M_B)
 =\frac1{N^2}\sum_hH(h)K_\beta(h)
 =\underbrace{J K_\beta(0)/N^2}_{\text{same physical plaquette}}
 +\underbrace{\sum_{h\ne0}H(h)K_\beta(h)/N^2}_{\text{distinct plaquettes}}.
\]
At \(\beta>0\), **use the measured interacting \(K_\beta(0)\)** in the same-site subtraction. The maximum per-configuration difference of the **direct vs histogram** raw contraction was \(2.11\cdot10^{-15}\) at L8 and \(2.61\cdot10^{-15}\) at L10 for beta two. The formal equality is exact original finite-torus integer geometry/algebra from VOL33; the finite floating accuracy is a separate runtime control.

What is being measured?

Each point represents a genuine original spatial 0–1 Wilson plaquette trace Pₓ=Re Uₚ on a periodic four-dimensional lattice. The connected two-point kernel Kβ(h) is measured for every displacement appearing in two paired spherical shells.

Cov(M_A, M_B) = J/N² × Kβ(0) + Σ(h≠0) H(h)/N² × Kβ(h)
Dynamical residual = total connected covariance − measured same-plaquette contribution.

The shared-point count J is exact integer geometry. At nonzero coupling, Kβ(0) is measured from the interacting field (≈0.135766 here), and the off-diagonal Kβ(h) captures correlations of distinct plaquettes. For F=(1+P)/2, all covariance values divide by four.

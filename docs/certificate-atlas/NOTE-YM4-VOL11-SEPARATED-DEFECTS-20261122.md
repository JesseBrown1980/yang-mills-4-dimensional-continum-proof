## 1. Model and exact incidence condition

Let \(\Lambda=(\mathbb Z/L\mathbb Z)^4\), \(L\ge3\). There are \(4L^4\) original positively oriented links and \(6L^4\) original plaquettes. Put
\[
W_p=\tfrac12\operatorname{Tr}U_p,\qquad
d\mu_{\beta,L}(U)=Z_{\beta,L}^{-1}
\exp\{\beta\sum_p W_p\}\prod_e dU_e^{\mathrm{Haar}},
\qquad\beta\ge1.
\]
Let \(\mathcal H_L\) be the graph on original positive links, where two vertices are adjacent iff they belong to the **same original plaquette**. Its degree is exactly 18, independently enumerated for every link in \(3^4\) and \(4^4\) in VOL10.

Choose an arbitrary finite independent set \(S\subset\mathcal H_L\), of size \(r\ge1\), and choose one of the six original incident plaquettes \(p(e)\) for each \(e\in S\). Such selected plaquettes are **distinct**, because two chosen links cannot belong to the same plaquette.

Write \(\mathcal F_{S^c}\) for the sigma-field generated by all *unselected* original links. The original Wilson action has **no plaquette involving two selected links**, so the Gibbs conditional law is exactly
\[
\boxed{
d\mu_{\beta,L}(U_S\mid\mathcal F_{S^c})
=\bigotimes_{e\in S}
\frac{\exp\{\beta\,u_e\cdot H_e\}}{Z(\beta|H_e|)}
\,dU_e^{\rm Haar},\quad H_e=\sum_{i=1}^6s_i(e).
}
\tag{1}
\]
Every preferred staple \(s_i(e)\) uses three **unselected** links. This is conditional product structure in the **full original SU2 Wilson measure**, rather than assumed independence of the gauge-invariant plaquettes in the unconditioned Gibbs state.

The fifteen-loop gauge-invariant good-star event from VOL08 is
\[
G_e(\epsilon)=
\bigcap_{1\le i<j\le6}
\{s_i(e)\cdot s_j(e)\ge1-\epsilon\}.
\]
For independent \(S\), **each \(G_e\) is \(\mathcal F_{S^c}\)-measurable**. The selected gauge-invariant plaquette defect is \(D_e(\delta)=\{W_{p(e)}\le1-\delta\}\), depending on the original selected link \(u_e\) and unselected exterior. Hereafter fix \(\epsilon=1/16,\delta=1/2\).

## 2. Exact continuous-SU2 Haar cap tail (analytical lemma)

Identify SU2 with the unit quaternions \(S^3\). For any fixed axis \(h\in S^3\), consider the Haar tilt \(d\nu_\kappa(u)\propto e^{\kappa(u\cdot h)}du\), \(\kappa\ge1\). Set \(T=1-u\cdot h\in[0,2]\). Under **untitled** normalized SU2 Haar, \(T\) has density
\[
\frac2\pi\sqrt{t(2-t)}\,dt.
\]
Therefore under the tilt \(e^{-\kappa T}\) the denominator satisfies the exact elementary bound
\[
\begin{aligned}
\mathbb E_{\rm Haar}[e^{-\kappa T}]
&\ge \frac2\pi\int_0^{1/\kappa}e^{-\kappa t}\sqrt{t(2-t)}\,dt\\
&\ge\frac1{2}\frac1{3}\int_0^{1/\kappa}\sqrt{t}\,dt
=\frac1{9\kappa^{3/2}}.
\end{aligned}
\tag{2}
\]
The second line uses \(2/\pi>1/2\), \(e^{-1}>1/3\), and \(2-t\ge1\) for \(0\le t\le1/\kappa\le1\). For any \(z>0\), the unnormalized numerator is at most \(e^{-\kappa z}\) because Haar measure is normalized. Thus
\[
\boxed{\nu_\kappa(T\ge z)\le
9\kappa^{3/2}e^{-\kappa z}.}
\tag{3}
\]
The proof concerns the **continuous Haar law**. Finite quaternion-subgroup fixtures in the checker are only for noncommuting *geometry*.

## 3. Strong local exponential bound on every original good exterior

On \(G_e(\epsilon)\), the original six-staple resultant satisfies
\[
6(1-\epsilon)\le |H_e|\le6,\qquad
s_i(e)\cdot h_e\ge1-\epsilon,\quad h_e=H_e/|H_e|.
\]
These follow by summing the fifteen pairwise Wilson-loop inequalities.

If the selected original plaquette is defective \(u_e\cdot s_i(e)\le1-\delta\), then the quaternion chordal triangle inequality gives
\[
|u_e-h_e|
\ge |u_e-s_i|-|s_i-h_e|
\ge \sqrt{2\delta}-\sqrt{2\epsilon}.
\]
Because \(\delta=1/2\ge4\epsilon=1/4\),
\[
1-u_e\cdot h_e=\frac12|u_e-h_e|^2
\ge\delta/4=1/8.
\tag{4}
\]
The conditional concentration parameter obeys
\[
\kappa_e=\beta|H_e|\in[45\beta/8,6\beta].
\]
Equations (3)–(4), \(\beta\ge1\) and \((6\beta)^{3/2}\le(6\beta)^2\) give a **uniform-over-all-good-exteriors** bound for the *original SU2 gauge-invariant plaquette defect*:
\[
\boxed{\mu_{\beta,L}(D_e(1/2)\mid\mathcal F_{S^c})
\le q_\beta:=\min\{1,324\beta^2e^{-45\beta/64}\}
\quad\text{on }G_e(1/16).}
\tag{5}
\]
No finite-group approximation, small-field Gaussian replacement or numerical SU2 integration is used.

For \(\beta=81\), an exact-rational 12-term Taylor partial sum \(\mathcal T_{12}(45\beta/64)=\sum_{j=0}^{12}(45\beta/64)^j/j!\) gives
\[
\boxed{q_{81}\le
\frac{324\cdot81^2}{\mathcal T_{12}(3645/64)}
<\frac1{1\,000\,000}.}
\tag{6}
\]
The finite integer checker verifies this strict inequality with exact numerator/denominator arithmetic. The all-beta analytic bound is (5); the rational Taylor sum is an **independent, reproducible upper envelope**, not a replacement for exponential inequalities.

## 4. Genuine joint original SU2 estimate and a controlled boundary term

Fix any independent set \(S\) and selected plaquette \(p(e)\) for every \(e\in S\). Because the selected original link conditionals factor exactly and the good events are complement-measurable, (5) yields
\[
\boxed{
\Pr_{\beta,L}\!\left(
\bigcap_{e\in S} D_e(1/2)
\ \cap\
\bigcap_{e\in S} G_e(1/16)
\right)\le q_\beta^r.
}
\tag{7}
\]
This is a **joint, exact original SU2 finite-volume theorem** for marked, distinct original Wilson plaquettes selected via non-plaquette-sharing pivot links. The exponential dependence on \(r\) is conditioned on the **simultaneous good-exterior event**, but the probability in (7) is taken in the full original Gibbs measure.

To state the best unconditional consequence available from the existing VOL09 certificate, set
\[
p_{\star}(\beta):=\sup_e\Pr_{\beta,L}(G_e(1/16)^c)
\le\min\{1,384\,R(\beta)\},
\]
where
\(R(\beta)=\beta^{-1}+\tfrac4{3\beta}\log(1536\beta^{3/2})\).
For independent \(S\) define \(N_{\rm bad}(S)=\sum_{e\in S}\mathbf1_{G_e^c}\), a function of the **unselected exterior links**. Conditional factorization and (5) imply
\[
\Pr(\cap_{e\in S}D_e)\le \mathbb E[q_\beta^{r-N_{\rm bad}(S)}].
\]
For any integer \(0\le t<r\), split on \(N_{\rm bad}\le t\) versus \(N_{\rm bad}\ge t+1\), then use Markov:
\[
\boxed{
\Pr_{\beta,L}(\cap_{e\in S}D_e(1/2))
\le \min\left\{
1,\ q_\beta^{r-t}+\frac{r\,p_{\star}(\beta)}{t+1}
\right\}.}
\tag{8}
\]
In particular, \(t=\lfloor r/2\rfloor\) when \(r\ge2\) gives
\[
\boxed{
\Pr(\cap D_e)\le
\min\{1,\ q_\beta^{\lceil r/2\rceil}+2p_{\star}(\beta)\}.}
\tag{9}
\]
For \(\beta=9^k\), VOL09's rational envelope provides
\[
\boxed{p_{\star}(9^k)\le\min\{1,128(35+18k)/9^k\}.}
\tag{10}
\]
Thus (8)–(10) are **actual original SU2 multi-plaquette probability bounds**, uniform across all finite periodic volumes, with an explicitly separated bad-exterior term.

**Quantitative qualification:** At fixed \(\beta\), the additive \(p_{\star}\) term prevents (8) from being an exponential-in-\(r\) *unconditional* island estimate. In the displayed weak-coupling examples, the earlier VOL09 one-plaquette marginal bound may be numerically smaller than the unconditional (8); retain the minimum of all available bounds.

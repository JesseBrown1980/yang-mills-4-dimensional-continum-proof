2. A PROOF WITHOUT BIRKHOFF, AND WHERE EQUALITY LIVES. DERIVED.
Let h be a real eigenfunction for mu != lambda_0, rho = h/Omega, x1 and x2 the points of largest and smallest rho.
P(x, dy) = K(x,y) Omega(y) / (lambda_0 Omega(x)) dy is a probability kernel, and P rho = theta rho.
With p = P(x1, .), q = P(x2, .): theta osc(rho) = integral (p - q) rho, so |theta| osc(rho) <= osc(rho) TV(p, q), and |theta| <= TV(p, q).
Let r = p/q, with range [r-, r+], r- <= 1 <= r+. With E = {r > 1}, a = q(E), b = p(E): b <= r+ a and 1 - b >= r- (1 - a), so TV = b - a <= min((r+ - 1) a, (1 - r-)(1 - a)) <= (r+ - 1)(1 - r-)/(r+ - r-).
Under r+ / r- = S fixed this is largest at r+ = sqrt S, r- = 1/sqrt S, where it equals (sqrt S - 1)/(sqrt S + 1). S is the largest of K(x1,y) K(x2,y') / (K(x1,y') K(x2,y)), since Omega and the norms cancel, so S <= R by Step 1, and sqrt R = (M/m)^N. So |theta| <= tau.
This replaces Steps 2 and 3 whole. It uses Omega > 0 and continuity, and it gives |theta| < 1 with no iteration whenever M/m is finite.
Equality. |theta| = tau > 0 forces r to take only the two values (M/m)^N on E and (M/m)^-N off E. Since r = c B(x1,y)/B(x2,y) and that ratio lies in [(M/m)^-N, (M/m)^N], c = 1, and for y in E every link has w(x1_l y_l^-1) = M and w(x2_l y_l^-1) = m, the reverse off E. On PH the same holds of every gauge image of y, because an average of values at most M^N equals M^N only when each equals it.
N >= 2 is impossible: take y in E, y' off E, and y'' with its first link from y and the rest from y'. Then B(x1,y'')/B(x2,y'') = (M/m)^(2-N), which is neither (M/m)^N nor (M/m)^-N. So the inequality is strict for N >= 2, on H and on PH, for every lattice and every weight with M > m.
N = 1: T is convolution by w, A = 1, and mu = integral w phi with phi = <v, rho(g) v>, integral phi = 0, |phi| <= 1. The same bound is attained only with phi = +-1 almost everywhere, so v spans a real character chi with kernel H of index 2, and w = M on H, m off H (mu > 0), or w = m on H, M off H (mu < 0). Continuity makes this hold everywhere, and H is closed and open.
On connected G, and so on SU(2), r is continuous on a connected space and cannot take two values, so the inequality is strict at every N.

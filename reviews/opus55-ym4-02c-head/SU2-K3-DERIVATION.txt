The note's CONJECTURE at k >= 3 on SU(2), read through. Second seat, November 4, 2026, at 40cc40d. Pencil proof, tag DERIVED by this seat, review OPEN, nothing run for it beyond the rows named at the end.

CLAIM. G = SU(2), w a bounded measurable class function, w != 0 almost everywhere, k >= 3. On L = (Z/2) x (Z/1)^(k-1) and on L = (Z/1)^k, S(C) = prod_p s(U_p) is almost everywhere constant if and only if s = sign w is almost everywhere constant. So on those lattices f >= 0 almost everywhere exactly when w has one sign almost everywhere.

SETUP. A class function on SU(2) is a function of the real part, so s(g) = sigma(Re g), with sigma = +-1 almost everywhere on [-1,1], since Re g has density (2/pi) sqrt(1-x^2). A plaquette through a side-2 direction holds a link once, so it is Haar distributed. A commutator has the density (pi-theta)/(2 sin theta) against Haar, in the note's line 63, so its law is absolutely continuous. So g != 0 almost everywhere, S = sign g almost everywhere, and Step 1 of the note gives: f >= 0 almost everywhere if and only if S is almost everywhere constant. The direction "s constant implies S constant" is immediate.

LEMMA A. Let D be an open subset of R^2 and sigma(x) sigma(y) = C for almost every (x,y) in D. Then sigma is almost everywhere constant on each connected open subset of the projection of D to x. Proof: around a point (x0,y0) of D take a rectangle I x J inside D. By Fubini, for almost every y in J, sigma(x) = C sigma(y) for almost every x in I, so sigma is almost everywhere constant on I. So sigma is locally constant, almost everywhere, on the projection.

CASE (Z/2) x (Z/1)^(k-1). Direction 0 has side 2, with links a, a' along it. Each side-1 direction j has links c_j at site 0 and d_j at site 1. The plaquettes are a d_j a^-1 c_j^-1, a' c_j a'^-1 d_j^-1, [c_i,c_j] and [d_i,d_j]. Replace c_1 by an independent copy c_1' and multiply the two values of S, which are both S = eps almost everywhere. Factors free of c_1 cancel since sigma^2 = 1. What holds a is the one factor pair, so for almost every value of everything else,
    a -> sigma(Re(a d_1 a^-1 c_1^-1)) sigma(Re(a d_1 a^-1 c_1'^-1)) is almost everywhere constant.
Put d_1 at angle alpha, c_1 = (cos gamma, sin gamma n), c_1' = (cos gamma', sin gamma' n'), with n, n' not parallel. x = a d_1 a^-1 = (cos alpha, sin alpha u), with u uniform on S^2, and Re(x c^-1) = cos alpha cos gamma + sin alpha sin gamma (u.n). The map u -> (u.n, u.n') is a local diffeomorphism off the great circle through n, n', so Haar pushes to a measure equivalent to Lebesgue on an open set, and for each t in (-1,1) the circle u.n = t leaves that great circle. Lemma A gives sigma almost everywhere constant on (cos(alpha+gamma), cos(alpha-gamma)). Almost every alpha, gamma occur, and alpha, gamma near pi/2 give an interval that fills (-1,1). So sigma is almost everywhere constant.

CASE (Z/1)^k. Links c_1 .. c_k, plaquettes [c_i,c_j]. Write a = c_1, b = c_2, and replace b by an independent copy b'. As above,
    a -> sigma(Re[a,b]) sigma(Re[a,b']) is almost everywhere constant, for almost every (b,b').
Put b = (cos beta, sin beta n), b' = (cos beta', sin beta' n'), n, n' not parallel. With R the rotation of a, Re[a,b] = cos^2 beta + sin^2 beta t, with t = (Rn).n, and Re[a,b'] = cos^2 beta' + sin^2 beta' t', with t' = (Rn').n'. Under Haar, R is Haar on SO(3). The differentials are dt = omega.(Rn x n) and dt' = omega.(Rn' x n'). Let U be the set where those two covectors are independent. For each t0 in (-1,1) there is R in U with t(R) = t0: fix u = Rn with u.n = t0, so A = u x n != 0; then w = Rn' runs over the circle around u at the angle between n and n', and B = w x n' is parallel to A or zero at finitely many w, because B is orthogonal to n', so B parallel to a nonzero A needs A orthogonal to n' and w in the plane orthogonal to A; that plane contains u, so it holds at most two points of that circle, and B = 0 holds at w = +-n'. U is open, with a null analytic complement, and (t,t') is a submersion on U, so Haar pushes to a measure equivalent to Lebesgue on the open set (t,t')(U), whose projection to t holds (-1,1). Lemma A gives sigma almost everywhere constant on (cos 2 beta, 1). Almost every beta occurs, and beta near pi/2 gives the interval (-1,1) in the limit, with every interval reaching up to 1, so the constants agree. So sigma is almost everywhere constant.

WHAT THIS USES. Connectedness of the range of the real part on SU(2), and that one conjugacy class is a 2-sphere. A finite group has neither, which is why Q8 keeps 16 of 32 there: runs/sign_walk_any.hbp, lattices 2x1x1 and 1x1x1, exhaustive.

FALSIFIER. A bounded class function on SU(2), nonzero almost everywhere and with both signs on sets of positive measure, whose S is almost everywhere constant on (Z/2) x (Z/1)^(k-1) or (Z/1)^k at some k >= 3. That is the note's own falsifier, and the proof above says it has none. A false step would be the place to attack: the submersion claim, and Lemma A's use on U.

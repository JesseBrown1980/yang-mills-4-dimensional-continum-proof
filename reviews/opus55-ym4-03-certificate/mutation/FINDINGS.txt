== F4. The four claims, by my own derivation ==
Claim 1 — survives, DERIVED. u = |u|(c Omega + s xi), xi in e = 0 orthogonal to Omega. With r_t = S u - rho u,
  |r_t|^2 = |u|^2 [c^2 (lambda_0 - rho)^2 + s^2 |(S - rho) xi|^2] >= |u|^2 s^2 min over lambda != lambda_0 of (lambda - rho)^2.
  Every other e = 0 value lies at or under first_high/2^shift < rho (gap > 0 is checked), so (lambda - rho)^2 >= (gap/2^shift)^2, and with
  r = <u,u> r_t: s^2 <= |r|^2 2^(2 shift)/(gap^2 <u,u>^3). Needs: S self-adjoint in the weighted product, u in e = 0 (flux_perron_vector_even),
  the level-1 bracket's high end above every non-ground e = 0 value, gap > 0. S >= 0 is not used here. Falsifier: a u with exact sin^2 above the
  bound; own code reads none at 2, 4, 40 steps on Z2 2x1.
Claim 2 — survives, DERIVED. Omega = c u/|u| + s eta with eta = s Omega - c xi, a unit vector orthogonal to u, so for w orthogonal to u,
  <w, Omega> = s <w, eta> and |<w, Omega>|^2 <= s^2 |w|^2. The ground's term in <w, S^(2n) w> 2^(2n shift) is then at most
  (sin2_num/sin2_den) |w|^2 ground_high^(2n), and each n's low with it taken off stays a lower bound, given every other value below the target in
  [-next_high, next_high] at scale 2^shift. full = <u,u> v - <u,v> u is orthogonal to u in integers, so the hypothesis holds exactly.
  Note, DERIVED: where a level bracket returns (0, 0) (Q8 e = 0, level 2) next_high = 0 counts the remaining values as 0; the step check gives only
  >= -2^-shift, so the rigorous rest term is max(next_high, 1)^(2n). Effect at most top_high^(-2n) of the share, about 2^-107 at n = 2 on Q8, and the
  earlier lane read those 78 values exactly 0 (factor x^78). No hold.
Claim 3 — survives, DERIVED. P w = |u|^3 (c P O Omega + s P O xi) - <u, v> |u| s P xi. If P O Omega = 0, |P w| <= |u|^2 s (|u| |O| + |v|), and
  (x + y)^2 <= 2x^2 + 2y^2 gives the square read. |F| <= max|f| (positive weights), |S^b| <= lambda_0^b <= (ground_high/2^shift)^b on every sector
  (flux_ground_in_e=0 puts the top in e = 0), so |F S^b F| <= max|f|^2 lambda_0^b. For e != 0, P F u = |u| c P F Omega + |u| s P F xi, and
  P F Omega = 0 gives |P F u| <= |u| s max|f|. The code's error_num/error_den equal these bounds term by term.
